# Houston Compaction

The USGS monitors a series of extensometers in the Houston area.  The compaction found my these sites is posted in an onilne [USGS publication](https://www.sciencebase.gov/catalog/item/5cd30a76e4b09b8c0b7a5cb3).  The map below was generated by scraping the data provided here.  

Documentation of the notebook workflow for collecting the data and generating the fplium map shown are registered in the Data Discovery entry for [Cumulative Compaction Houston](https://ckan.tacc.utexas.edu/dataset/cumulative-compaction-houston) site.
